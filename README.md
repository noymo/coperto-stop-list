# Coperto Stop List

Тестовое задание на позицию Middle Frontend Developer.

Панель управления стоп-листом ресторана: просмотр позиций меню, фильтрация по цеху и статусу, постановка позиции в стоп-лист, редактирование причины и срока стопа и возврат позиции в продажу.
